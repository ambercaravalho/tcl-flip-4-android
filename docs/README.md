## Research

[`findings/`](findings/) is the chronological evidence record.
[`reference/`](reference/) holds durable facts, and [`runbooks/`](runbooks/)
holds repeatable procedures.

Before device work, read the latest applicable finding and runbook, record the
starting state, and follow [AGENTS.md](../AGENTS.md). Completed findings are
historical; correct them with a later session rather than rewriting them.
