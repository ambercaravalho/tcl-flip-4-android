# T440W Android 14 v0.1.0

Initial alpha release for the TCL Flip 4 5G / Go Flip 5G model T440W.

## Working

- persistent 240x320 client-composed physical display
- physical navigation and upgrade-safe toggleable D-pad cursor
- microG and Aurora Store
- enforcing SELinux and authenticated non-root ADB
- Magisk-managed per-app root

Telephony, cameras, Bluetooth, carrier behavior, and broad app compatibility are not yet release-tested.

## Install

Clone the repository and run `tooling/scripts/install-release.sh`. The guided installer downloads and verifies these release images, requires a full device-bound backup, checks the exact T440W identity/GPT/slot, and reads every written range back before reboot.

Read the [installation guide](https://github.com/ambercaravalho/tcl-flip-4-android/blob/v0.1.0/docs/guides/install.md). This release supports only an exact-layout T440W already active on slot B.

## Important

EDL writes can permanently brick a phone. Returning to stock requires that phone's verified full eMMC backup; metadata alone is insufficient. The AVB chain uses public AOSP test keys.

The included prebuilt `vendor_dlkm_b` contains a binary-patched GPL `msm_drm.ko`, but the exact matching TCL 6.1 source is unavailable. This unresolved corresponding-source risk is documented in `SOURCE_PROVENANCE.md`.
