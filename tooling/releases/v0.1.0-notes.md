# T440W Android 14 v0.1.0

Initial alpha release of the experimental Android 14 ROM for the TCL Flip 4
5G / Go Flip 5G model T440W (`gflip5gtmo` / `pitti_32go`).

## Validated profile

- stable 240x320 physical display;
- physical Back, Home, Messages, and D-pad navigation;
- C9 cursor toggle, movement, click, and conditional scrolling;
- hidden on-screen navigation bar;
- enforcing SELinux and authenticated non-root ADB;
- Magisk 31.1 application root, denied until explicitly granted;
- microG Services and Companion;
- Aurora Store anonymous browse, download, and Session Installer.

This profile was validated on one reference phone. Telephony,
carrier-specific behavior, cameras, Bluetooth, and broad application
compatibility do not yet have release acceptance gates.

## Install

Read the complete
[v0.1.0 installation guide](https://github.com/ambercaravalho/tcl-flip-4-android/blob/v0.1.0/docs/guides/install-v0.1.0.md)
before downloading or writing anything.

The release targets phones already active on slot B and the exact reference
T440W GPT geometry; the installer does not change GPT slot metadata. Make a
full verified eMMC backup and device-bound receipt first. EDL writes can
permanently brick the phone.
Reads use `--skipresponse`; writes never do; every written range must be read
back and compared before reboot.

Download all eight `.img` assets plus `SHA256SUMS` and
`release-manifest.json`. The two system extents are the complete system
payload; there is no monolithic system image.

## Security and recovery

The phone boots locked/green, but the AVB chain is signed with public AOSP test
keys rather than a private production key. Returning to stock requires the
same phone's verified full eMMC backup; a metadata-only rollback is not
sufficient.

Magisk Manager is carried outside package-scanned directories. Install it
normally under `/data/app` only after all flash read-backs and post-boot gates
pass.

## Source caveat

The prebuilt `vendor_dlkm_b` contains a binary-patched GPL `msm_drm.ko`. The
exact matching TCL 6.1 source is unavailable; TCL's available disclosures are
unrelated 4.19/5.15 trees. This release includes the hash-locked patch tooling
and reconstruction evidence, but the missing corresponding source remains an
unresolved GPL compliance risk.

See `SOURCE_PROVENANCE.md`, the source/provenance archive, and the tagged
repository for component versions, licenses, modifications, and source
commits.
